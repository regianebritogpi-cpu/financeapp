FINANCEAPP - VERSÃO PWA INSTALÁVEL

O que foi incluído:
- manifest.json
- service-worker.js
- ícones 192px e 512px
- configuração para instalação pelo Chrome/Android
- funcionamento offline básico após primeiro acesso

COMO INSTALAR NO CELULAR ANDROID:
1. Publique esta pasta no Vercel.
2. Abra o link no Google Chrome do celular.
3. Toque nos 3 pontinhos do Chrome.
4. Escolha "Adicionar à tela inicial" ou "Instalar aplicativo".
5. O FinanceApp ficará com ícone na tela do celular.

COMO INSTALAR NO COMPUTADOR:
1. Abra o link publicado no Google Chrome.
2. Na barra de endereço, procure o ícone de instalação.
3. Clique em "Instalar".
4. O app abrirá como janela própria.

IMPORTANTE:
- Para a instalação PWA funcionar corretamente, o app precisa estar em HTTPS.
- O Vercel já fornece HTTPS gratuito.
- Abrir apenas o arquivo HTML local pode não ativar todos os recursos PWA.
